# MoovHeal — Test mobile

Ce dossier contient une version web testable du prototype MoovHeal.

## Pour obtenir un lien public rapidement
1. Va sur https://app.netlify.com/drop
2. Glisse-dépose le fichier `index.html` ou le dossier complet
3. Netlify génère automatiquement un lien partageable
4. Ouvre ce lien sur ton téléphone

## Alternative
Tu peux aussi créer un projet Vercel ou GitHub Pages avec ce `index.html`.

Note : cette version utilise React + Babel via CDN, donc il faut une connexion Internet pour charger React au premier affichage.
